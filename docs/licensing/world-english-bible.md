# World English Bible licensing review

Review date: 2026-08-07

## Selected edition

- Name: World English Bible
- Abbreviation: WEBP
- Source identifier: `engwebp`
- Language and dialect: English, American
- Canon: 66 books, without the Deuterocanon/Apocrypha
- Source edition: 2020 stable text edition

The official edition page states that WEBP is otherwise identical to the World
English Bible Updated.

## Licensing findings

- **Copyright:** the text is dedicated to the Public Domain.
- **Offline redistribution:** permitted; the publisher explicitly permits copying,
  distributing, redistributing, sharing, and backing up the text.
- **Commercial use:** permitted; the publisher explicitly permits selling the text.
- **Quotation limits:** none stated; the publisher permits quoting and using the text
  without a quantity limit.
- **Modification:** permitted by its Public Domain status, but a changed text must not
  be called the World English Bible.
- **Attribution:** no attribution or royalty is required. Verski should still display
  the edition name and official source so users can identify the text.
- **Trademark:** “World English Bible” is a trademark. The name may identify only a
  faithful copy of the official text.

## Rules for Verski

1. Import verse text faithfully, without editorial corrections.
2. Keep the source identifier `engwebp` and the source edition in translation
   metadata.
3. Link to the official edition page in attribution information.
4. Do not claim copyright over the imported Public Domain text.
5. If the text is ever changed, use a different translation name.
6. Record the downloaded package version or date and checksum when source data is
   added.

## Decision

WEBP is suitable for Verski's initial small static dataset, including offline and
commercial distribution, provided that Verski preserves the text faithfully when
using the World English Bible name.
